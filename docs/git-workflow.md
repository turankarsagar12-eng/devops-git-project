# Git Workflow Documentation

## Main Branch
The main branch contains the stable project version.

## Development Branch
The dev branch is used for ongoing development.

## Feature Branch
Feature branches are used to develop individual changes.

## Commits
Git commits record changes to the project.

## Pull Requests
Pull requests allow changes to be reviewed before merging.

## Git Tags
Tags identify specific project versions.

## Merge Conflicts
Merge conflicts occur when Git cannot automatically combine changes.
