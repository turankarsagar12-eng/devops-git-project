# Version-Controlled DevOps Project with Git

## Project Overview
This project demonstrates version control using Git and GitHub.

## Objective
To manage a DevOps project using Git best practices.

## Tools Used
- Git
- GitHub
- Git Bash
- Visual Studio Code

## Tasks Completed
- Initialized a Git repository.
- Created main, dev, and feature branches.
- Practiced commits and merging.
- Used pull requests.
- Added a .gitignore file.
- Created Git tags.
- Documented the Git workflow.

## Project Structure
- index.html: Sample project webpage.
- README.md: Project documentation.
- .gitignore: Files excluded from Git tracking.
- docs/git-workflow.md: Git workflow documentation.
